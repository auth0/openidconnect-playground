# Architecture Decision Records

Append-only log of decisions that are costly to reverse. Format: MADR-style, `NNNN-title-with-dashes.md`. Never edit an accepted ADR's decision; supersede it with a new one and link both.

Write an ADR when: adding a dependency/framework, choosing a stack profile, changing a rendering/caching strategy, allow-listing a third party, setting or changing a budget, or deviating from the constitution.
